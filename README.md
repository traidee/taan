# EmpoderaJobs - Portal de Empleo para Mujeres

EmpoderaJobs es una propuesta de sitio web para un tablero de anuncios clasificados enfocados exclusivamente en **oportunidades laborales para mujeres**.

El objetivo de esta plataforma es conectar el talento femenino con empresas inclusivas que ofrezcan condiciones justas, brecha salarial cero, trabajo remoto o híbrido, y apoyen el liderazgo de las mujeres en todas las industrias.

## Características de la propuesta

- **Interfaz Moderna y Empoderadora:** Diseño limpio y profesional utilizando Tailwind CSS y una paleta de colores morados, símbolo de la equidad de género.
- **Buscador de Empleos:** Sección destacada (Hero Section) con inputs para buscar por cargo y ubicación.
- **Sectores Profesionales:** Categorías como Tecnología, Finanzas, Diseño, Salud, Educación y Marketing para facilitar la navegación.
- **Vacantes Destacadas:**
  - *Senior UX/UI Designer* (Remoto, TechNova Solutions).
  - *Directora de Finanzas (CFO)* (Híbrido, Grupo Financiero Inclusivo).
  - *Ingeniera de Software Backend* (Remoto, EcoTech Startup).
  - *Especialista en Marketing Digital* (Medio Tiempo, Agencia Creativa Violeta).
- **Llamado a la Acción para Empresas:** Sección dedicada a invitar a empresas a publicar sus vacantes inclusivas y encontrar el mejor talento.
- **Responsivo:** Diseño 100% adaptable a dispositivos móviles, tablets y computadoras de escritorio.

## Tecnologías Utilizadas

- **HTML5:** Estructura semántica de la página.
- **Tailwind CSS:** (Vía CDN) Framework de CSS para el diseño rápido, moderno y responsive de la interfaz.
- **FontAwesome:** (Vía CDN) Para la iconografía de las categorías y empleos.
- **Google Fonts:** Tipografía `Inter`.

## Instrucciones para visualizar el prototipo

Dado que el proyecto está construido puramente con HTML estático y Tailwind CSS vía CDN, no requiere de una instalación compleja.

1. Clona o descarga el repositorio.
2. Abre el archivo `index.html` en tu navegador web de preferencia (Chrome, Firefox, Safari, Edge).
3. ¡Explora el prototipo de EmpoderaJobs!
